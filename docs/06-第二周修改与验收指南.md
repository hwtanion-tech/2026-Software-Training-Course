## 4 切换到 MySQL（正式课程技术栈）

默认 demo 便于立即验收，课程报告需要 MySQL 截图时请使用本节。H2 数据不会自动复制到 MySQL，两者分别保存。你的常驻 3306 数据库未被本轮测试修改。

### 4.1 初建数据库

先停止后端。从 database 目录进入 MySQL 客户端（输入你自己的数据库管理员密码）：

```powershell
Set-Location -LiteralPath 'G:\file\grade 4 first semester\PRACTICE\campus-news-system\database'
mysql -u root -p --default-character-set=utf8mb4
```

在 MySQL 提示符执行：

```sql
SOURCE schema.sql;
SHOW TABLES FROM campus_news;
```

应有 `sys_user`、`news_category`、`news`、`notice`。文件不会删除旧表或自动迁移列。若以前手动改过结构，先与 schema.sql 对照。建议使用项目专用账号，在 MySQL 中执行并自行替换密码占位文字：

```sql
CREATE USER 'campus_app'@'127.0.0.1' IDENTIFIED BY '替换成你自己的数据库密码';
GRANT SELECT, INSERT, UPDATE, DELETE ON campus_news.* TO 'campus_app'@'127.0.0.1';
EXIT;
```

账号已存在时核对后沿用，不要重复创建。数据库密码和网站管理员密码是两件事。

### 4.2 启动并初始化网站管理员

在 backend 的 PowerShell 终端设置环境变量。下面通过隐藏输入读取密码，不把明文写入源码或命令历史：

```powershell
Set-Location -LiteralPath 'G:\file\grade 4 first semester\PRACTICE\campus-news-system\backend'
$env:SPRING_PROFILES_ACTIVE = 'mysql'
$env:DB_USERNAME = 'campus_app'
$env:DB_URL = 'jdbc:mysql://127.0.0.1:3306/campus_news?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&connectTimeout=3000&socketTimeout=5000'
$dbSecret = Read-Host '数据库账号密码' -AsSecureString
$env:DB_PASSWORD = [System.Net.NetworkCredential]::new('', $dbSecret).Password
$env:BOOTSTRAP_ENABLED = 'true'
$env:BOOTSTRAP_USERNAME = 'admin'
$appSecret = Read-Host '首次创建的网站管理员密码（12至64位）' -AsSecureString
$env:BOOTSTRAP_PASSWORD = [System.Net.NetworkCredential]::new('', $appSecret).Password
Remove-Variable dbSecret, appSecret
mvn spring-boot:run
```

初始化仅在 `sys_user` 完全为空时执行，不覆盖任何已有用户和密码。已有用户时不会重置管理员。用户名须 3～50 位字母/数字/下划线；密码 12～64 位，应用存 BCrypt 哈希。MySQL 库首次没有新闻/分类样例，登录管理员后先创建分类，再新建新闻和通知。

首次成功启动后按 Ctrl+C 停止，在同一终端移除初始化变量，然后正常重启：

```powershell
Remove-Item Env:BOOTSTRAP_ENABLED, Env:BOOTSTRAP_PASSWORD, Env:BOOTSTRAP_USERNAME -ErrorAction SilentlyContinue
mvn spring-boot:run
```

前端启动方式不变，仍访问 5173。MySQL 模式登录页面不显示演示账号。不要再设置旧版 `DB_ENABLED`；它已不控制连接。

需要切回 demo 时，先停止后端，再清理 MySQL 及初始化环境变量，然后启动：

```powershell
Remove-Item Env:SPRING_PROFILES_ACTIVE, Env:DB_URL, Env:DB_USERNAME, Env:DB_PASSWORD, Env:BOOTSTRAP_ENABLED, Env:BOOTSTRAP_USERNAME, Env:BOOTSTRAP_PASSWORD -ErrorAction SilentlyContinue
mvn spring-boot:run
```

### 4.3 可重复的接口验收

从项目根目录执行，脚本会提示输入网站管理员密码（demo 是 `DemoAdmin!2026`，mysql 是你设置的密码）：

```powershell
Set-Location -LiteralPath 'G:\file\grade 4 first semester\PRACTICE\campus-news-system'
& .\scripts\smoke-test.ps1 -BaseUrl 'http://127.0.0.1:8080' -Username 'admin'
```

脚本使用真实 Cookie/CSRF，检查管理员登录、数据库连接、分类、新闻和通知新增/编辑/发布/搜索分页/撤回/删除及退出。会新增一个带时间标记的分类，完成后停用保留，并删除本脚本创建的测试新闻/通知。仅在你的本地验收库使用。中途失败时会停止并显示错误，已创建的测试数据可能保留，可在后台按标题定位。若 PowerShell 执行策略阻止脚本，不必全局修改策略，先手工执行页面验收或在允许脚本的开发终端运行。

## 5 常见问题与阅读顺序

- 5173 页面连接失败：确认 `npm.cmd run dev` 正在运行；以终端显示端口为准。
- 8080 被占用：先停止旧后端，避免双开；若改后端端口，需同步改 `frontend/vite.config.js` 的 dev/preview 代理。
- 页面显示连接错误：访问 `/api/health` 确认后端存活，再看后端终端。
- MySQL 启动失败：核对实例、密码、数据库名、四表是否导入；不要把启动失败当作演示模式成功。
- `/api/health/database` 返回 401/403：这是管理员诊断接口，需登录管理员；匿名健康检查用 `/api/health`。
- 写操作 403：可能会话过期或 CSRF 失效；刷新并重新登录，再执行一次。前端不会自动重发写操作。
- 停用分类发布失败：把新闻换到启用分类再发布；已有公开新闻不会被分类停用自动撤回。
- demo 密码不能登录 MySQL：MySQL 使用显式初始化的管理员，演示账号只存在 demo 库。

推荐按 `ContentController → ContentService → ContentRepository → Models` 阅读后端，再读 `SecurityConfig` 和 `CurrentUser`；前端按 `App.vue → api.js → ManageContent.vue` 阅读。先掌握“请求在哪里校验、权限在哪里检查、状态在哪里修改、SQL在哪里执行”，方便答辩解释。
